### ***Projeto Final POO - Sistema de Loja***

# 

##### ***Descrição***



###### Sistema de gerenciamento de uma loja desenvolvido em Java utilizando conceitos de Programação Orientada a Objetos (POO).



###### ***Funcionalidades***



\* Login de funcionários;

\* Cadastro de funcionários;

\* Listagem de funcionários;

\* Cadastro e consulta de pagamentos;

\* Abertura e fechamento de caixa;

\* Pagamentos via PIX, boleto e cartão;

\* Geração de relatório.



###### ***Tecnologias***



\* Java 17

\* Maven

\* NetBeans



###### ***Como executar***



1\. Abra o projeto no NetBeans.

2\. Faça o ***Clean and Build***.

3\. Execute o projeto.
